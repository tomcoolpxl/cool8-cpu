COOL8 Quick Reference

Shortcuts

F1Warm Restart (Ctrl+Esc)
F10Cold Restart (Ctrl+Shift+Esc)
F11Break Button (NMI) — stops running program
F12Save Screenshot PNG
Alt+EnterToggle Fullscreen
Ctrl+VPaste text from clipboard

Discs & Files

DRIVE 13Switch to Demo Disc
DIRList directory of current drive
LOAD "NAME"Load program from drive
SAVE "NAME"Save program to current drive
RUNRun loaded program
NEW / LISTClear program / list code

Graphics & Audio

MODE nSet screen mode (0=Text 80x30, 1=Text 40x30, 4=Bitmap 320x240 16-col)
CLG cClear graphics screen with colour c
PLOT x, y, cPlot pixel at (x, y) with colour c
LINE x0, y0, x1, y1, cDraw line from (x0, y0) to (x1, y1) with colour c
GTEXT x, y, s$, cDraw 8×8 graphic text in bitmap modes
VSYNCWait for vertical blanking (60 Hz pacing)
SOUND v, p, dur, volPlay audio note on voice (0..7)
